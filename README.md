# Schedule One personal mods

Private monorepo for personal Schedule I beta mods. The target installation is the Steam **beta / IL2CPP** branch, initially inspected at **0.4.7f5**, Steam build **25622691**, with MelonLoader **0.7.2** and S1API **2.5.0**.

Planned independently installable mods:

| Mod | Purpose |
| --- | --- |
| Warehouse | Keep the warehouse vendors accessible around the clock and add existing storage furniture to their catalog. |
| BetterPolice | Restore tougher pursuit, vision, detection and shooting against the current beta APIs. |
| Highballer | Update the old customer offer optimizer and handover features. |
| Casino | Raise casino betting limits separately from customer deal optimization. |
| MoreGuns | Repair and update the old custom weapons, registration and shop integration. |

This repository is for the owner's personal use. Permission to adapt the old mods was supplied by the owner; it is not a grant of redistribution rights. Game assemblies, third-party binaries, extracted weapon assets, decompiled reference source, saves and local configuration are excluded from Git. No public releases are intended.

Implementation and verification are in progress. Build and installation instructions will be recorded as each module is completed.
