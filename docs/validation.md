UI Enhancements 0.2.1 addresses these issues against the newly installed 0.4.7f10 beta; detailed live verification remains pending.

The owner then confirmed the player glyph looks correct and requested direction in the minimap. UI Enhancements 0.2.2 follows horizontal local-camera heading and refreshes peer POI direction independently of native phone-map updates. In-game directional verification remains pending.
